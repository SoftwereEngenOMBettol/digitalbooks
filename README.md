# Color Your World — متجر كتب تلوين

موقع Static عربي RTL (مع مبدّل عربي/إنجليزي) لمتجر كتب التلوين الرقمية، بخلفية ألوان مائية
متحركة تتفاعل مع حركة المؤشر، وانتقالات ناعمة بين الشبكة وصفحة المنتج.

## الملفات

| الملف | المحتوى |
| --- | --- |
| `index.html` | بنية الصفحة والنصوص العربية (المصدر الوحيد للنص العربي) |
| `style.css` | التنسيقات، متغيرات الألوان والمنحنيات في `:root` |
| `script.js` | محرك السوائل، الترجمة، البطاقات، الانتقالات، التلوين التفاعلي |
| `assets/` | أغلفة الكتب (`.webp` خفيفة للعرض، و`.png` الأصلية محفوظة)، رسمة التلوين، وفيديو الخلفية |

## حجم الأصول

الأغلفة كانت تُشحن بصيغة PNG بحجم 1254×1254 (‏6.6MB مجتمعة) لتُعرض بعرض 250 بكسل.
النسخ المستخدمة الآن `.webp` بعرض 640 بكسل — **193KB مجتمعة**. ملفات PNG الأصلية باقية
في `assets/` كمصدر، ولا يطلبها المتصفح.

## خلفية الفيديو

`assets/colors.mp4` يعمل خلفيةً للصفحة، لكنه **لا يُطلب إطلاقًا قبل أن تُرسم الصفحة**:
الوسم في HTML بلا `src`، ويضيفه `initVideo()` بعد حدث `load` وفي وقت خمول. طبقة السوائل
تغطي المشهد إلى أن يصبح الفيديو جاهزًا فلا يظهر وميض أبيض، ثم يتلاشى الفيديو إلى الظهور
فوقها. ولا يُطلب أبدًا مع `prefers-reduced-motion` أو `saveData` أو اتصال من فئة 2g،
وإن تعذّر فك ترميزه تُزال طبقته وتبقى السوائل.

**ما زال الملف ثقيلًا: 6.7MB بترميز H.264 ومعه مسار صوت** لا حاجة إليه في خلفية صامتة.
لم يكن ضغطه ممكنًا هنا (نسخة ffmpeg في بيئة التطوير مجرّدة من فك ترميز mp4). للضغط محليًا:

```sh
# يحذف الصوت ويصغّر المقاس — يُتوقع أن ينزل الحجم إلى ما دون 1.5MB
ffmpeg -i assets/colors.mp4 -an -vf "scale=1280:-2" -c:v libx264 -crf 30 -preset slow \
       -movflags +faststart assets/colors.min.mp4

# نسخة WebM أخف للمتصفحات التي تدعمها
ffmpeg -i assets/colors.mp4 -an -vf "scale=1280:-2" -c:v libvpx-vp9 -crf 40 -b:v 0 \
       assets/colors.webm
```

بعدها بدّل المسار في `initVideo()` داخل `script.js`.

## الحركة والتأثيرات

| التأثير | التنفيذ |
| --- | --- |
| خلفية الفيديو | `assets/colors.mp4` بتحميل مؤجَّل ومشروط (`initVideo`) — تفاصيله في قسم خلفية الفيديو أعلاه |
| التدفق السائلي | شادر WebGL مكتوب يدويًا (`initFluid`) بتشويه نطاقي fbm، يتبع المؤشر بتتبّع بطيء وتتلاشى دفعته خلال ~1.2s؛ يظهر فورًا ويغطي زمن تحميل الفيديو |
| التدرجات المبتكرة | أربع كتل لونية بـ `blur: 85–120px` تدور ببطء (`.blob`) |
| ملء التلوين | `assets/coloring-balcony.png` رسمة خطية بخلفية **شفافة**؛ قطرات لونية تتراكم تحتها مع حركة المؤشر فتبدو كأنها داخل الخطوط |
| أدوات التلوين | 12 لونًا جاهزًا + وضع ألوان متعاقبة + منتقي HSV كامل، ومزلاج فرشاة من 2% إلى 40% من عرض اللوحة. التلوين **بالضغط والسحب** لا بمجرد المرور |
| المؤشر المنزلق في الشريط | حبة تنزلق بين روابط التنقل وتتبع الرابط النشط (`moveInd`) |
| مروحة الأغلفة | الأغلفة الحقيقية في ترتيب ثلاثي الأبعاد تميل مع المؤشر (`initShowcase`) |
| انتقال العناصر المشتركة | FLIP: الغلاف يطير من البطاقة إلى صفحة المنتج (`openSheet` / `closeSheet`) |
| الانثناء ثلاثي الأبعاد | `rotateX/rotateY` مع تتبّع مرن للمؤشر على الكتاب والبطاقات |
| التمرير الطبقي | `data-parallax` على الأقلام والعنوان والكتاب بمعاملات مختلفة |
| المؤشر السائل | 22 قطرة ملونة تتلاشى خلال ثانية واحدة |

**قواعد الأداء:** كل الحركات محصورة في `transform` و `opacity`. حلقات `requestAnimationFrame`
تتوقف عند بلوغ هدفها بدل الدوران الدائم. شادر السوائل يُرسم بـ 34% من دقة الشاشة ثم يُمدّ،
فينتج نعومة مائية بتكلفة رسم زهيدة. المنحنى الموحّد `cubic-bezier(.16,1,.3,1)` والمدد بين
300ms و 500ms.

## التوافق والوصول

- يعمل الموقع كاملًا بدون GSAP: إن تعذّر تحميل المكتبة تعمل الحركات عبر Web Animations API.
- إن تعذّر WebGL يظهر تدرّج CSS احتياطي بدل الشادر.
- `prefers-reduced-motion` يوقف السوائل والمؤشر والبارالاكس ويُظهر المحتوى ثابتًا.
- مربع التشبّع ومزلاج الدرجة والإدخال السداسي مثبّتة على `direction:ltr`؛ تدرّجاتها مرسومة من
  اليسار لليمين، فلو تُركت لاتجاه الصفحة RTL لانعكس موضع المقبض ولم يطابق اللون الذي تحته.
- تنقّل كامل بلوحة المفاتيح، `Escape` يغلق صفحة المنتج، وروابط تخطٍّ وحلقات تركيز ظاهرة.

## التعديل

- **النصوص العربية** في `index.html` داخل عناصر تحمل `data-i18n="key"`.
- **الترجمة الإنجليزية** في الكائن `EN` أعلى `script.js` — أي نص جديد يحتاج مفتاحًا في الاثنين.
- **المنتجات** في مصفوفة `BOOKS` — زر «شراء الآن» يأخذ رابطه من `url` مباشرة.
- **ألوان المنتقي الجاهزة** في مصفوفة `SWATCHES` أعلى `script.js`.
- **الألوان والمنحنيات والمدد** في `:root` أعلى `style.css`.

## ما زال ناقصًا

- **غلاف كتاب التلوين 3**: يُولَّد حاليًا رسم ماندالا بديل. ضع الصورة في `assets/cover-book3.png`
  ثم اضبط `cover` للكتاب الثالث في `BOOKS` على المسار.
- **رسمة التلوين**: واحدة فقط (`coloring-balcony.png`). لإضافة غيرها، بدّل `src` الصورة في
  قسم `#studio`، أو اجعلها قائمة يختار منها الزائر. الصورة مولَّدة من ملف JPEG أصلي بتحويل
  الأبيض إلى شفاف وتكميم قناة الشفافية إلى 16 مستوى (413KB بدل 687KB).
- **صفحات نموذجية** داخل صفحة المنتج لزيادة ثقة المشتري.
- **نموذج الكتالوج** يتحقق من البريد في المتصفح فقط؛ يحتاج ربطًا بخدمة بريدية لإرساله فعليًا.
